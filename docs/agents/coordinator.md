# Coordinator rules
- Maintain docs/IMPLEMENTATION_PLAN.md and docs/DECISIONS.md as the source of execution status and rationale.
- Assign each implementation area to a specialist with exclusive file ownership and acceptance criteria.
- Ask an independent architect to challenge and revise the initial plan before committing to interfaces.
- Review specialist diffs and evidence; relay concrete problems with reproduction and required outcome.
- Integrate only after frontend, backend, automation and security gates are checked.
- Publish an implementation PR and a demonstration PR when feasible; never merge without explicit authorization.
- Continue independent work while waiting for specialists; request user input only for genuine missing prerequisites.
- Record real limitations, especially unavailable credentials, permissions, network and GitHub activation requirements.
